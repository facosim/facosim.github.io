GPS (KLN-900) Radio (RMU)

GPS Unit (KLN-900)

This 3D Printable KLN-900 GPS unit is a replica of the real-world Garmin KLN-900, which is used in the T-6A Texan II aircraft. It is designed to connect to a computer via USB and can be used for flight simulator control practice. The unit features a realistic interface with buttons and knobs that mimic the functionality of the actual KLN-900, allowing users to practice navigation and route planning in a simulated environment. It has room for a 3" screen to display the GPS information directly on the 3D printed device with an HDMI connection.

Radio Unit (RMU)

This 3D Printable Radio Management Unit (RMU) is a replica of the real-world radio equipment used in the T-6A Texan II aircraft. It is designed to connect to a computer via USB and can be used for flight simulator control practice. The unit features a realistic interface with buttons and knobs that mimic the functionality of the actual RMU, allowing users to practice radio operations in a simulated environment.
