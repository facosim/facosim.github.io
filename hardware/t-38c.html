T-38C Training Tools (3D Printable)

Disclaimer: The model files are available freely but may require some significant modifications to work with your specific flight simulator setup.

Up Front Control Panel (UFCP)

This 3D Printable UFCP allows pilots to practice using the primary data entry tool of the T-38C avionics system. It is designed to be used with a USB Keyboard encoder board and HDMI display output of a 3" screen, allowing pilots to practice using the UFCP in using a flight simulator.

Download Contact for Pre-Assembly

Multi-Function Display (MFD)

This 3D Printable MFD covers a 10.1" display to simulate the primary avionics display of the T-38C. It is designed to be used with a USB encoder board and HDMI display output, allowing pilots to practice using the MFD in using a flight simulator.
